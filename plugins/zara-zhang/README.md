# Zara Zhang

This plugin indexes public skills from [zarazhangrui](https://github.com/zarazhangrui).

## Included Skills

- `call-me`
- `codebase-to-course`
- `follow-builders`
- `frontend-slides`
- `podcast`
- `youtube-to-ebook`

## Notes

- `frontend-slides` contains both a root `SKILL.md` and an identical nested packaged copy at `plugins/frontend-slides/skills/frontend-slides/SKILL.md`. This plugin indexes the root skill once and keeps the full root template assets needed by that skill.
- Repositories without `SKILL.md` were not indexed.
